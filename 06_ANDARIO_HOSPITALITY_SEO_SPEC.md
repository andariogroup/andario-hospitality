# ANDARIO HOSPITALITY — SEO SPECIFICATION
Version: 1.0
Status: Initial SEO strategy
Date: 2026-09-22

## 1. SEO objective

The SEO strategy exists to make Andario Hospitality discoverable by:

1. Accommodation owners looking for digitalization services.
2. Accommodation owners looking for websites, SEO or booking technology.
3. Independent accommodation businesses looking for direct-booking solutions.
4. Tourism entrepreneurs looking for practical digital tools.
5. Future Latin American customers searching in English or Spanish.

SEO is not a promise of first position.

The objective is to build a technically sound, useful, trustworthy and semantically coherent website that can earn relevant organic visibility over time.

# 3. Search intent model

## A. Commercial intent

The user is evaluating a solution.

Examples:

- motor de reservas para hoteles
- página web para hoteles
- SEO para hoteles
- software para hostales
- reservas directas hotel
- digitalización hotel

Primary target pages:
Service pages and Booking Engine.

## B. Informational intent

The user is learning about a problem.

Examples:

- cómo recibir reservas directas
- qué es un motor de reservas
- cómo reducir dependencia de Booking
- cómo hacer una página web para un hostal
- cómo posicionar un hotel en Google
- qué necesita un hotel para vender directamente

Primary target:
Future resources/blog/guides.

## C. Local/commercial intent

The user combines service + geography.

Examples:

- motor de reservas hoteles Colombia
- página web para hoteles Colombia
- SEO para hoteles Colombia
- digitalización de hoteles Colombia
- software para alojamientos Colombia

Future regional pages should be created only when they provide genuinely useful localized content.

## D. Traveler intent

Examples:

- hotel en Valledupar
- hostal en Buritaca
- apartamentos turísticos en Cartagena

These are not primary keywords for Andario Hospitality's corporate site.

They belong primarily to customer projects and their local SEO strategies.

# 18. Bilingual SEO

Spanish is the initial primary language.

English is the second language.

Each equivalent page must have:

- language-specific URL
- unique localized content
- correct `<html lang>`
- canonical
- reciprocal `hreflang`
- language switcher

For example:

Spanish:
`https://andariohospitality.com/es/soluciones/booking-engine`

English:
`https://andariohospitality.com/en/solutions/booking-engine`

Use:

- `hreflang="es"`
- `hreflang="en"`
- `hreflang="x-default"` when a suitable fallback is implemented.

Google recommends that each language version reference itself and the other language versions, with reciprocal annotations. citeturn0search1

Do not translate only the navigation while leaving the main content essentially identical. Localized pages should contain genuinely localized main content. citeturn0search1turn0search3

---

# 19. Canonical strategy

Each indexable page should have a self-referencing canonical URL unless there is a specific reason otherwise.

Canonical URLs must use the final HTTPS domain.

Example:

`https://andariohospitality.com/es/`

Canonical is a signal, not an absolute command; Google can select another canonical when its systems determine another URL is more representative. citeturn0search3

---

# 20. XML Sitemap

Create an XML sitemap containing only canonical, indexable, public URLs.

Initial sitemap should include:

- Spanish pages
- English pages
- service pages
- cases when published
- future editorial content

Do not include:

- redirects
- noindex pages
- duplicate URLs
- query parameter variations
- admin pages
- internal search results

Submit sitemap through Google Search Console.

---

# 21. Robots.txt

Robots should:

- permit normal public crawling
- reference sitemap
- block private/admin paths if they exist
- not be used as a substitute for `noindex` when a URL must remain crawlable but not indexed

Example conceptual structure:

User-agent: *
Allow: /

Sitemap: [production sitemap URL]

The final file will depend on the technical architecture.

---

# 35. SEO principle

**SEO is not a separate layer added after development.**

The site architecture, content, UX, performance, accessibility, internal linking and technical implementation must be designed together.

The goal is not to "trick Google."

The goal is to make Andario genuinely useful and understandable to:

**the accommodation owner + the search engine + future AI/search experiences.**
