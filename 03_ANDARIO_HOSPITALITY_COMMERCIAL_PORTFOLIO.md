# Commercial assembly model

Services are not sold as a mandatory fixed bundle.

Example:

### Accommodation A
Andario Web + Booking Engine

### Accommodation B
Digital Check + Web + Visibility + Booking Engine

### Accommodation C
Digital Check + Web + Visibility + Booking Engine + Connect + Content + Growth

The final proposal is personalized according to the establishment's situation, objectives and budget.
